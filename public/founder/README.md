# Founder assets (playbook Part 1, Jobs 4/5)

Drop the real assets here and the landing page's founder note swaps them in
automatically (no code change — see src/components/landing/FounderNote.tsx):

- `photo.jpg` (or .png / .webp) — a real photo, ~640×640 or larger, square crop.
- `story.md` — the story in your own words. Format:

  ```
  # Your Name
  First paragraph of the story.
  Second paragraph.
  ```

  One paragraph per line. The `# ` first line is optional and becomes the
  signature line.
